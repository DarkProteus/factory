Игрок выбирает здание на панели и кликает по карте. Интерфейс проверяет место, кладёт команду build в очередь, на ближайшем тике ядро ставит здание, рендер рисует его на следующем кадре.

## Steps

| From | To | Action |
| --- | --- | --- |
| [Игрок](../actors/player.md) | [Интерфейс](../systems/factory/containers/browser-game/components/ui.md) | Выбирает здание, кликает по карте |
| [Интерфейс](../systems/factory/containers/browser-game/components/ui.md) | [Ядро симуляции](../systems/factory/containers/browser-game/components/sim.md) | Передаёт команду build на тике |
| [Интерфейс](../systems/factory/containers/browser-game/components/ui.md) | [Рендер](../systems/factory/containers/browser-game/components/render.md) | Просит нарисовать кадр |
| [Рендер](../systems/factory/containers/browser-game/components/render.md) | [Ядро симуляции](../systems/factory/containers/browser-game/components/sim.md) | Читает новое здание из состояния |
