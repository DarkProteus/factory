## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Плейтест 2026-11-21: в плотном заводе каждый столб соединяется со всеми в радиусе 7, провода идут паутиной крест-накрест. Ограничить автосоединение несколькими ближайшими (как в Factorio, до 5), с детерминированным выбором при равных расстояниях. Связность сетей не должна теряться без нужды — решить и записать правило (основная сессия).
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решение (грилинг 2026-11-21, записано в design.md «Веха M3: решения»): провода — минимальное остовное дерево (Kruskal) по парам столбов в радиусе 7; ребро сравнивается по квадрату длины, затем по паре id (меньший, больший). Выведенный кеш рядом с сетью, сбрасывается по topologyVersion. Связность сетей та же, что сейчас; сейв и хеш не меняются. Рендер рисует только рёбра дерева. N ближайших как в Factorio не используется: история постройки не хранится.
