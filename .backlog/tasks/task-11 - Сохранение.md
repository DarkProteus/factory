## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Веха M1. Система «Сохранения», пакет `save`: запись и загрузка партии. Партия длится 3–6 часов, без сохранений в игру нельзя играть. Корректность проверяется хешем состояния из TASK-4: загруженная партия должна быть неотличима от исходной, включая состояние генератора случайных чисел.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Состояние с картой, зданиями, предметами на конвейерах и в буферах сохраняется и загружается
- [ ] #2 После сохранения и загрузки хеш состояния совпадает с исходным
- [ ] #3 Загруженная и исходная партии после ещё 1000 тиков с одинаковыми командами дают одинаковый хеш
- [ ] #4 Сохранение содержит номер версии формата; загрузка неизвестной версии даёт понятную ошибку
- [ ] #5 Тесты идут без браузера
- [ ] #6 Загрузка сохранения со зданием, которого нет в content, не роняет игру, а выдаёт понятную ошибку
<!-- AC:END -->
