## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Веха M1. Пакет `app` на React превращает ввод игрока в команды для `sim`. Без него в M1 нельзя играть: игроку нечем ставить и сносить здания. Управление — мышь и клавиатура.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Архитектурные решения (основная сессия, 2026-11-20):
- sim: проверка места выносится из placeBuilding в чистую функцию canPlace(state, type, x, y, dir, defs?) и экспортируется из sim; placeBuilding вызывает её. Поведение placeBuilding не меняется (его тесты не трогать).
- Интерфейс не меняет состояние: клик кладёт команду build/demolish в очередь, игровой цикл в App.tsx передаёт очередь в tick(state, commands) на ближайшем тике и очищает её.
- Клетка под курсором: renderer.camera.screenToWorld, затем floor(/CELL). Якорь призрака — левая верхняя клетка отпечатка, отпечаток с учётом dir (footprintSize); курсор указывает на центр отпечатка (для 2×2 — смещение на клетку).
- render получает метод setOverlay(overlay | null): { ghost?: { building, x, y, dir, valid }, highlight?: { x, y, demolish: boolean }, grid: boolean }. Render только рисует оверлей, valid считает app через canPlace.
- Призрак рисуется теми же функциями зданий, что и настоящее здание, но в режиме призрака: в draw/shapes.ts функция fill() и контуры берут цвет из текущего режима (ok/bad α 0.35, контур α 0.8). Без тени, лампы и анимации (tick и alpha = 0). Сетка в радиусе 6 клеток вокруг призрака — линии 1 px grid.
- Подсветка: рамка 2 px text по отпечатку здания под курсором, в режиме сноса — bad.
- Интерфейс на React поверх canvas, строго по docs/style.md (панели, кнопки 48 px, шрифты @fontsource Oswald / IBM Plex Sans / IBM Plex Mono, CSS-переменные --<токен> с теми же значениями, что palette.ts). Клавиши 1–9 — здания по порядку content.buildings, X — снос, R — поворот, Esc — снять инструмент. Номер тика — левый верхний угол.
- Иконка здания на кнопке — его форма с карты в ориентации N, вписанная в 24 px: маленький PixiJS-рендер не нужен, допустим SVG/canvas2d по тем же размерам, но лучше переиспользовать draw-функции render (Pixi Graphics -> отдельный маленький Application или extract) — на усмотрение исполнителя, главное соответствие style.md.
- Левая кнопка — строить/сносить; панорама остаётся на средней/правой кнопке (controls.ts).
