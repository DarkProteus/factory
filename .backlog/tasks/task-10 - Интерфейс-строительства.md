## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Веха M1. Пакет `app` на React превращает ввод игрока в команды для `sim`. Без него в M1 нельзя играть: игроку нечем ставить и сносить здания. Управление — мышь и клавиатура.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Панель зданий показывает доступные здания из `content`; клик выбирает здание для постройки
- [ ] #2 Перед установкой под курсором виден полупрозрачный «призрак» здания, привязанный к сетке
- [ ] #3 Призрак показывает, что место занято или недоступно
- [ ] #4 Клавиша R поворачивает призрак; здание ставится с выбранным направлением
- [ ] #5 Клик ставит здание через команду `sim`, интерфейс не меняет состояние напрямую
- [ ] #6 Снос убирает здание под курсором через команду `sim`
<!-- AC:END -->
